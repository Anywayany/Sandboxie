The executable payload in this directory is generated by the manual workflow:

  .github/workflows/build-picoclaw-payload.yml

It builds Windows x64 output from Anywayany/picoclaw branch wendi-mobile-h5.
Because that branch currently omits its embedded workspace templates, the
workflow copies only the workspace directory from the same repository's main
branch before building. Exact commits and SHA-256 hashes are recorded in:

  payload-manifest.json

The locally tested Windows payload applies:

  patches/windows-native-dns.patch

This keeps the native Windows resolver instead of treating the missing
/etc/resolv.conf as an Android environment.

Required files before packaging:

  picoclaw-launcher.exe
  picoclaw.exe
  payload-manifest.json
  LICENSE.picoclaw.txt

The executable files are ignored by Git. Run "npm run verify:payload" after
extracting the workflow artifact here and before creating the installer.

Do not place provider credentials or a user config.json in the application
package. PicoClaw keeps its configuration in the per-user PicoClaw directory,
whose writes are redirected by PicoClawBox.
